What's New · 2.1

2.1 版本更新亮点

这一版重点把已经变多的入口重新整理，让日常使用更顺手，业务页面与数据均保留可用。

导航收口为树形菜单

左侧栏从 22 个入口收成 7 个一级入口；销售、财务、售后、设置改为可展开树形菜单，一次只展开一个，当前子项高亮清晰。

自定义主题色

设置 → 外观可选蓝、青、绿、橙、紫、粉或自定义取色；主题色保存在账号上，换电脑登录仍保留，每位员工可独立设置。

首页与库存仓库分工

首页只负责经营概览、快捷操作、待办提醒与最近动态；完整设备明细统一收进库存仓库，职责更清楚。

修复选中菜单与当前标签看不清的问题；父级只做浅色提示，不再整块蓝色，避免误判当前页。

安卓快递扫码保留

店内模式继续支持销售出库、寄修、寄卖的快递单号扫码，自动回填，兼容 Code128、Code39、QR 等常见面单条码。

Upgrade

升级步骤

覆盖安装不会删除业务数据，但升级前仍建议先手动备份数据库。

先备份

管理员进入「设置 → 备份与恢复」点立即备份，把 .db 文件复制到 U 盘或另一台电脑，确认备份文件存在。

覆盖安装

退出旧版机掌柜，运行新的 Setup 安装包覆盖安装；安卓端用新 APK 覆盖安装即可。

核对数据

打开程序，检查库存、客户、账号与主题色；进入店内模式核对扫码、登录与库存是否正常。

FAQ

常见问题

手机连不上电脑主机？▾

确认手机和电脑在同一局域网、电脑 IP 没有变化、防火墙已放行 3001 端口；可在「手机连接」重新扫描配对二维码后再试。

Android 端怎么使用？▾

安卓主界面进入「店内 / 服务端」，使用电脑主机的 Web 界面；在销售出库、寄修、寄卖表单中可扫码自动回填快递单号。外勤收机入口当前版本隐藏，数据保留未删除。

数据保存在哪里？会不会上云？▾

数据保存在门店电脑的 SQLite 数据库中，不上公有云。建议每天自动备份、每周手动备份，把备份文件放到另一块硬盘或 U 盘；数据库含客户、手机号、IMEI、价格与照片，请按敏感数据保管。

升级后数据会不会丢失？▾

2.1 只做增量迁移，不改设备表结构、不删表、不清空业务数据。若升级后感觉数据不见，先不要重装或重置，确认是否登录同一数据库，再用升级前备份在「备份与恢复」中恢复。

销售看不到进货价、毛利或金额？▾

这是角色权限控制的结果。请管理员在账号权限中检查：查看进货价、查看毛利、销售开单、查看全店销售等开关；销售默认仅可见自己的金额与毛利。

提成没有生成？▾

依次检查：销售账号已启用提成、提成值大于 0、出库人是销售账号；管理员 / 店长自己销售的单据不计提成。退货退款后对应提成会自动冲销。

打印机不出纸？▾

检查 USB 打印机是否连接、驱动是否安装、打印机名称是否正确、纸张是否为 40×60，再到「设置 → 打印设置」中检测打印机。
